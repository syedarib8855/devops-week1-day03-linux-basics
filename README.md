
# Day 3: Linux Basics and CLI Commands

## Objective
Learn basic Linux commands and create simple Bash scripts.

## Commands Practised
- ls: List files and directories
- cd: Change directory
- mkdir: Create directories
- touch: Create files
- cat: Display file contents
- grep: Search text
- find: Find files and directories
- chmod: Change file permissions
- chown: Change file ownership
- top: Monitor running processes
- ps: Display running processes

## Scripts
1. system_info.sh - Displays basic system information.
2. create_files.sh - Creates a folder and three files automatically.

## What I Learned
I learned basic Linux navigation, file management,
permissions, process monitoring, and Bash scripting.
